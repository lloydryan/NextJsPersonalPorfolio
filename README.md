# Lloyd Ryan Largo Portfolio

This is a Next.js portfolio app built with TypeScript, React, Bootstrap, AOS, Framer Motion, and React Icons.

## Scripts

- `npm run dev` starts the local Next development server.
- `npm run build` creates a production build.
- `npm run start` serves the production build.
- `npm run lint` runs ESLint.

## Routes

- `/`
- `/about`
- `/works`
- `/achievements`
- `/connect`
